# DecisionPath

「未选择的路」的 iOS 原型。`DecisionPath` 是工作名，产品名未定。

记录一个人真实选择过的 A 与 B，以及选择之后真实发生的感受。不替用户做选择，也不虚构没选的那条路的结果。

## 产品循环

1. 说出此刻的纠结
2. 整理成两条路
3. 选择一条
4. 到约定时间回访，记录真实感受
5. 同类选择积累后对比

## 设计约束

- 只在犹豫的时刻产生记录。样本不是「所有日子」，而是需要答案的那些日子；洞察必须带上这个条件。
- 不用打卡、连续天数和推送做留存，所以第 1 条记录就要产出价值。预期折进选择的手势：按住路标上推，既选了 A 也表达了预期，回访后即得「你以为 4 分，实际 7 分」。
- AI 只做选项二分，不给建议和评价。模板命中走本地，未命中走云端。洞察语气按样本量分三档：1 条只陈述、2 条只并列、≥3 条才允许比较级。

## 技术

- UIKit 负责输入、状态编排和可访问控件
- SpriteKit 负责道路、人物行走与视差
- 程序化布局，无 Storyboard，无 SwiftUI
- iOS 17+，Swift 5

## 状态

原型跑通了一条闭环：人物持续行走 → 输入纠结 → 路标出现 → 选择后穿过 → 继续前行。

待做：决策记录与回访的数据模型、云端服务协议与错误降级、VoiceOver 与动态字体适配。
